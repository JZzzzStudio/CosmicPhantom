# 领域共享语言（CONTEXT）

> 本文件是项目的领域共享语言：所有需求/设计对话必须使用本文件定义的术语，边聊边更新。
> 定义必须是无歧义的声明式句子。达成共识立即写回；难逆决策进入决策卡，规格和实施票据进入 `work/<slug>/`，不创建 ADR 目录。

## 文件职责

- `.context/CONTEXT.md` 只保存当前有效的共享语言、关系和业务规则。
- 用户确认的难逆决策进入决策卡；规格与实施票据进入 `work/<slug>/`；收尾档案进入 `pro/`。
- 历史补记、宿主档案和一次性验证结果不得继续堆入本文件；需要追溯时保留在对应档案，并在这里只留下当前有效结论。
- `DIRECTORY-MAP.md` 说明目录和数据流；本文件只定义语义，不重复目录清单。

## 术语

- 术语：示例
  定义：一句话无歧义定义。

## 关系

- 关系声明（如：X 与 Y 是 1:N，X 拥有零个或多个 Y）。

## 业务规则

- 规则声明（如：删除 X 时若 Y 仍绑定，不允许删除，必须先解绑）。
