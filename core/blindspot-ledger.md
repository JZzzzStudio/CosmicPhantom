# 盲区账本（看不见的部分 · 母级/子级）

> 立档 2026-09-16（用户定为**新的最高优先级**）：解决「你看不见的那部分还有多少，你不知道」。
> 起点：跨宿主衔接成熟度自评暴露的两句话——「一天自己造 3 个雷，说明是稳定产出率」「这三个还都是我自己发现的，我看不见的还有多少，我不知道」。

## 0. 这套账本承诺什么、不承诺什么（先读这段，否则会被它骗）

**承诺**：把「无限的黑」换成 **4 个有刻度的口袋 + 一组会动的数字**。
**不承诺**：
- 账本能数清**已知未知**（可枚举）；**未知的未知**只能用**抽样误报率**估计其规模（**下界**，非全量）。
- 不可证伪的东西（"我压根没想到的"）**进不了子级**——发现它只能靠 A/C 的机制**持续跑**，不能靠列清单。
- 因此**永远存在一个不可枚举的残差**。看到数字好看 ≠ 盲区小，只代表**这次观测没抓到**。

## 1. 母级合法性判据（防分层本身变成负优化）

> **母级的合法性来自"判据不同"，不来自"内容不同"**（沿用既有先例：`absorbed-notes` 横向 / `improvement-ledger` 纵向 分账，理由是"卡在谁"不同）。

一条母级**只有同时满足**下列三点才可独立存在，否则**必须并入或删除**：
1. 有**专属检测手段**（别的母级替代不了）
2. 有**专属数字**（可比较、可看趋势）
3. 有**专属超期/越界判据**（能触发动作，不是只看）

**自应用检查（每次新增母级时重跑）**：任意两母级的检测手段若收敛为同一个 → 合并。

## 2. 子级合法性判据

子级 = **一条可证伪的假设，或一条可核实的声明**。必须写清：
- 我**依赖它成立**才能往下做（否则不算盲区）
- 它**如何被证伪**（具体命令/观测点）
- 当前状态：`未观测` / `已观测`（附观测证据） / `已证伪`（附推翻证据）

> 不可证伪的条目**不进子级**（如"用户会不会突然改主意"）——那类只能靠机制持续跑。

## 6. 对账法（机械生成假设清单，取代"靠我想"）

> **动机**：账本只能装"我想到了要问的"。v0 立档当天就暴露此缺口——**真正危险的是我没想到要问的问题**。
> **对策**：CP 的强项是对账（coverage 逐 mid、F23 grep 台账、audit-due 比 mtime）→ 把"回想"换成**可复跑的机械枚举**。

**四个提取口（2026-09-16 实跑，可重跑）**：

| # | 提取什么 | 命令要点 |
| --- | --- | --- |
| ① | 我向宿主声明的 hook 事件 | `grep -oE '"(SessionStart\|UserPromptSubmit\|Stop\|PreToolUse\|PreCompact\|SubagentStart\|PostToolUse)"' ~/.claude/settings.json` |
| ② | 代码引用的宿主配置路径 | `grep -rhoE '\.(claude\|zcode\|proma\|workbuddy\|codebuddy)[\\/]...' --include=*.{js,cjs,mjs}`（**必须排除 node_modules/backup**） |
| ③ | 依赖的环境变量 | `grep -rhoE 'process\.env\.[A-Z_]+' --exclude-dir=node_modules --exclude-dir=tests` |
| ④ | 运行时前提 | `grep -rl "experimental-sqlite"` 的脚本数（= 全部引擎脚本都依赖该 flag） |

**对每条依赖点问三问**（答不全即入账本）：
1. 谁**写入**它？（没有 → 新机落地靠手工 = 盲区）
2. 谁**验证**它？（没有 → 坏了没人知 = 盲区）
3. 我**观测**过它真实生效吗？（没观测 → `未观测`）

**首跑战果（2026-09-16）**：抓到 **B-004**（主宿主接入件无人写、无人验）——这条**纯靠回想是想不到的**，证明方法本身有效。
⚠️ **方法自身的缺陷（同轮暴露）**：首跑的环境变量扫描**没排除 `node_modules`**，误把三方库的变量（NODE_TLS_REJECT_UNAUTHORIZED 等）当成 CP 依赖；第二次 grep 又因模式过宽导致"每个模式匹配同一批文件"（等于没区分）。→ **对账命令必须自带范围限定，否则产出假清单**（同"判据设计不严"家族）。

## 7. 维护纪律

1. **触发**：发现新的"我在赌某个东西"的地方 → **当场**记一条，不等收尾
2. **不许自我美化**：数字难看就难看；**"已观测"必须带观测证据**（文件/命令输出），无证据 = `未观测`
3. **母级自检**：每次新增母级/子级后，重跑 §1 的自应用检查（两母级手段收敛 → 合并）
4. **越界即报**：A 有阻塞性未观测项 / B 任一级 0 次 / C 误报率超阈值 → `verify` 报红
5. **蒸馏联动**：收工语义 → 蒸馏时顺带过一遍本账（与改进台账同款清账时刻）
