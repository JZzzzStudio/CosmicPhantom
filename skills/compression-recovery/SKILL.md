# 🧪 压缩恢复（compression-recovery）

> 可复制、可搬运：本 skill 自包含全部规则，不依赖任何宿主平台特性（借鉴 agentmemory PreCompact 思路——业界标准是压缩前重新注入，本 skill 是压缩后自觉恢复，因宿主无 PreCompact 类钩子）。复制本目录到任意宿主 skills 目录即可用；所有路径用 `<根>` 占位（= Cosmic Phantom 系统根，见 README.md 与当前宿主配置），跨机改一处即可。

## 🎯 目标
上下文被折叠后，在 30 秒内恢复三件事：**我是谁**（门禁+用户画像）、**说过什么**（最近决策/原话）、**正在干什么**（接力状态/下一步）。恢复后立刻能无缝继续工作，不重复问用户已答过的问题。

## 🚨 触发条件（任一出现即执行，不要等用户要求）
1. **压缩信号**：上下文明显不完整（引用的旧内容对不上、提到"之前说过"但自己没印象、模型失忆症状）
2. **失忆信号**：用户问"还记得我吗""我们上次聊到哪""之前那个XX是怎么回事"
3. **新会话开场**：开场即发现上下文里没有门禁/当前状态（未走新会话协议第 0-1 步）

## ⚠️ 触发局限与定位（2026-08-12 审查补实，必须知道）
- **失忆者不知道自己失忆**：本 skill 靠自觉触发，若压缩后连"该恢复"都想不起来，skill 永远不会执行——这是本 skill 的先天边界，不是用法错误。
- **真正的强执行是开场注入**：AGENTS.md 状态快照段（宿主自动注入）+ MCP `instructions`（连接即带状态）——新会话即使完全失忆，状态也在场。
- 因此本 skill 定位是**二道防线（兜底）**：开场注入失败 / 会话中途压缩 / 用户点名要恢复时执行；"不自知失忆"场景靠开场注入覆盖。

## 🔄 恢复流程（严格三步，缺一不可）

### 第 1 步：低 Token 恢复胶囊（先看状态）
```bash
node "<根>/resume-context.js" render --root "<根>"
```
- 输出：统一门禁 + 当前状态（revision/objective/nextActions/blockers）+ 最近工作速览
- 预算：约 3200B，30 秒内读完
- 这一步只读，不写任何数据

### 第 2 步：完整身份卡（补画像与最近原话）
```bash
node "<根>/inject.js" --lens "<当前任务一句话>" --root "<根>"
```
- 输出：用户画像（称呼/性格/沟通偏好）+ 今日/最近原话 + 门禁细节
- `--lens` 传当前任务关键词，身份卡会带上相关记忆上下文
- **失忆 fallback（2026-08-12 补）**：如果连"当前任务"都想不起来（第 1 步胶囊里的 objective 可作 lens；仍不确定就**省略 --lens 直接跑**——已验证可正常输出身份卡，不要卡在这一步）

### 第 3 步：细节检索（按需，不要全查）
```bash
node "<根>/memory-cli.js" search "<关键词>" --root "<根>"
```
- 只在第 1-2 步信息不够时用：查历史决策、术语、具体项目事实
- 禁全量翻 daily/*.md（Token 爆炸），只查需要的条目

## ✅ 恢复后行为（必须做）
1. 向用户**一句话确认恢复状态**，三要素缺一不可：①报 revision 号 ②报当前 objective ③复述最近一件决策/成果（真恢复的证明，不是复述文件）
2. 主动接受用户追问验证：用户问"那上次那个 XX 怎么回事"时，能用第 3 步检索现场答上——答不上就直说"这条要查"，不装记得
3. 若当前状态与用户当下要求矛盾 → 以用户当下要求为准，但指出状态里记录的旧目标
4. 若发现恢复内容与上下文记忆冲突 → 以 `<根>/current-state.json` 为准，冲突点向用户点明
5. 恢复完成后正常继续工作；本会话结束时按会话结束协议落盘

## 🗂️ 与其它 skill 的分工
- **memory-first-workflow**：日常任务开始前的"先搜记忆"习惯，与恢复无关
- **universal-workflow**：通用工作流（澄清→计划→执行→验证），压缩恢复是其前置步骤
- **distill-conversation**：会话收尾的蒸馏归档，恢复的是"过去"，蒸馏管"归档"

## ⚠️ 注意
- 本 skill 是**自觉触发**（宿主无 PreCompact 类钩子，平台压缩信号不可编程监听）；宁可多恢复一次，不可漏恢复
- 恢复后禁止假装记得：胶囊里没有的内容就说"这条要查"，用第 3 步检索
- 身份卡预算有限（1800B），`inject.js` 输出可能截断——截断部分用第 3 步补齐
