# 文档导航

CP 的公开文档按读者任务组织。首页先说明它解决的问题；实现文档说明边界和限制，不代表所有能力都已通过真实部署验收。

| 你要做什么 | 从这里开始 |
|---|---|
| 了解 CP 的目标、适用范围和快速自检 | [仓库 README](../README.md) |
| 阅读英文简介和快速开始 | [README in English](../README.en.md) |
| 把 CP 接到 Agent 环境或实例目录 | [接入与配置契约](AGENT-CONFIG.md) |
| 理解事件、候选、活跃记忆和检索边界 | [架构与不变量](ARCHITECTURE.md) |
| 阅读 CP 的首版产品闭环和完成标准 | [产品设计](PRODUCT-DESIGN.md) |
| 打包、配置、启用或卸载通用插件 | [插件包说明](PLUGIN-PACKAGE.md) |
| 使用统一术语 | [术语表](TERMINOLOGY.md) |
| 查看固定题集、指标定义和已知局限 | [评测口径](../eval/METRICS.md) |
| 报告安全问题、了解可公开数据边界 | [安全与隐私](../SECURITY.md) |
| 提交改动或可复现缺陷 | [贡献指南](../CONTRIBUTING.md) |

## 公开状态说明

- 三域 API/CLI 已有隔离实现和测试，但三域产品规格仍为草案；旧数据迁移和默认检索/注入切换没有启用。
- 评测指标只适用于文档明确标出的题集、参数和口径；小题集结果不能外推成普遍用户收益或答对率。
- 通用插件包的本地测试不等于已验证所有 Agent 宿主、安装器、升级器或断电恢复路径。
- `docs/legacy/` 中的文件仅用于历史复现，不是当前安装入口。公开发布前必须完成历史文件和 Git 历史的敏感信息扫描。
