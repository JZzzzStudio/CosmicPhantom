# 术语表

> 这是公共文档的共享词汇。实例层的 `.context/CONTEXT.md` 可以补充项目规则，但不能重新定义下表术语。

| 术语 | 唯一含义 | 默认来源/去向 |
|---|---|---|
| 原始事件（raw event） | 接入端提交的单条用户、Agent 或工具记录；保留来源身份、时间、作用域和正文，作为可回放证据 | `events.db`；投影到 `daily/` |
| 事件来源身份（event identity） | 区分来源实例、来源记录 ID 和必要 revision 的稳定身份；正文哈希只能校验或受限回退，不能单独合并不同记录 | 适配器 → `events.db` |
| 日期日志（daily log） | 从原始事件按日期、会话和通道生成的可读投影，不是新的事实源 | `events.db` → `daily/` |
| 提纯候选（candidate） | 从会话或工具中提取、尚未获得用户明确确认的长期记忆提案 | `candidates/`；不进入默认注入 |
| 活跃记忆（active memory） | 已经通过确认门、可参与默认检索和注入的记忆卡 | `memories/` |
| 提纯档案（distilled archive） | 对过期日志或历史材料的人读归档；可帮助回顾，但不替代原始事件或活跃记忆 | `distilled/` |
| 当前状态（current state） | 跨窗口接力用的结构化状态：目标、摘要、下一步、阻塞和验证结果；不是完整聊天记录 | `current-state.json` |
| 检索资产（retrieval assets） | 由活跃记忆生成的索引、向量和关系图；缺失时可以重建或降级 | `memory-index.db`、`embedding-db/`、`links.json` |
| 适配器（adapter） | 将某种 transcript、JSONL 或手动输入转换为统一事件的边界组件；不直接决定长期记忆 | 接入端 → 标准事件 |
| 验证（verification） | 对格式、来源覆盖、派生层指纹、隐私出口、同步状态和降级统计进行的可重复检查 | `memory-cli.js verify` |
| 作用域（scope） | 内容适用范围：`global`、`workspace` 或 `agent`；不是多用户权限模型 | 记忆卡和候选元数据 |
| 出处（provenance） | 说明内容来自哪条事件、哪次提纯、哪位确认者和哪个时间点的来源链 | 候选、活跃记忆和评测结果 |
| 证据准入（admission gate） | 检索结果进入模型上下文前的资格判定；排序分数本身不能证明答案成立 | 检索器 → 注入层 |
| 派生层（derived layer） | 可由明确输入删除并重建的文件或数据库，不得反向覆盖真源 | 日志、索引、向量和关系图 |
| 公开入口（public surface） | GitHub 首页、README 和当前公开文档入口；不得暴露个人路径、凭据、内部宿主版本或私有接线细节 | 发布前检查 |

## 生命周期

```text
接入输入
  → 适配器
  → 原始事件
  → 日期日志

提纯
  → 候选
  → 用户明确确认
  → 活跃记忆
  → 检索资产
```

- 原始事件是证据层；日期日志、提纯档案和检索资产不能反向覆盖它。
- 候选和活跃记忆必须物理分离；没有确认 provenance 的内容不能伪装成活跃记忆。
- 当前状态记录正在做什么，活跃记忆记录跨任务仍成立什么；两者不能互相替代。
- 所有自动增强都必须可观察地降级；绿色测试不等于生产质量已经证明。
